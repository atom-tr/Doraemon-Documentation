# Privacy Policy

**Last Updated:** \[Feb 12th, 2025]

This Privacy Policy explains how **Doraemon** Bot handles user data.

**1. Data We Collect**

The Bot only collects minimal data required for its functionality:

* **User IDs**: Used to track player progress in the roleplaying game.
* **Server IDs**: Used to store server-specific settings (if applicable).
* **Message Content**: Only processed in real-time to check if it matches a valid command. **We do not store or log message content.**

**2. How We Use the Data**

* User and server IDs are used to manage game progress and settings.
* Message content is temporarily checked to process bot commands but **not stored or shared**.

**3. Data Sharing & Security**

* **We do not sell, share, or distribute any user data** to third parties.
* All stored data is limited to essential functionality and is **not personally identifiable**.
* If users request data removal, we will comply as required.

**4. User Control & Opt-Out**

* Users can remove their data by leaving the Discord server where the Bot is present.
* Server administrators can remove the Bot at any time to stop data processing.

**5. Changes to This Policy**

We may update this Privacy Policy as needed. Continued use of the Bot after changes implies acceptance of the new policy.

If you have any concerns, please contact us at [Support Server](https://discord.gg/7QAZe6QP8U).
